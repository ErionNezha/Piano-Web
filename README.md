# Piano Web

Piano klasike në browser me HTML/CSS/JS — 11 taste (të bardha e të zeza) me tinguj realë piano, klikim me miun dhe tastierë.

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.

## 📁 Struktura
- `index.html`
- `demo/index.html`
- `demo/piano.css`
- `demo/piano.js`
- `original/piano.html`
- `original/piano.js`

## 🖥️ Si ekzekutohet origjinali
Hap demo/index.html — kliko tastet ose përdor A,S,D,F,G,H,J (të bardha) dhe W,E,T,Y,U (të zeza).
